# Game of Chaos

元胞自动机沙盒。第一版是标准的康威生命游戏，规则层已经抽出来，
后续把五状态生克、异步因果这类规则接进同一个沙盒。

零构建：没有打包器、没有 npm 依赖，浏览器直接跑 ES 模块。

## 运行

任选一种：

```bash
# Python（Windows 上一般自带）
python -m http.server 8080

# Node
npx serve .
```

然后打开 <http://127.0.0.1:8080>。

> 直接双击 `index.html` 也能打开，但 `file://` 下浏览器会拦掉 ES 模块，
> 所以本地起个静态服务器最省事。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 画活细胞 |
| 右键拖动 / Shift + 左键 | 擦除 |
| 空格 | 播放 / 暂停 |
| `.` 或 `s` | 单步 |
| `c` | 清空 |
| `r` | 随机撒点；选中图样时改为旋转图样 |
| `g` | 切换网格线 |
| `Esc` | 取消待放置图样 |

右侧面板可以改规则串（`B3/S23` 这种写法）、选预设规则、调速度与密度、
切换边界环绕、换网格尺寸。设置会存在 localStorage 里。

图样面板点一下选中，再在画布上点一下盖章。

## 结构

```
index.html            页面骨架
css/style.css         深色主题样式
js/core/board.js      网格数据（TypedArray 双缓冲、环绕/非环绕）
js/core/rules.js      B/S 规则解析与格式化
js/core/engine.js     演化引擎（同步更新、出生/死亡统计、存活年龄）
js/ui/renderer.js     Canvas 渲染、坐标拾取
js/ui/patterns.js     图样库（字符画 + RLE 解码）
js/app.js             装配层：循环、输入、控件绑定
tests/engine.test.mjs 引擎回归测试（node 直接跑）
```

引擎不碰 DOM，渲染不碰规则，所以能把同一套引擎放到 Node 里跑测试。

## 测试

```bash
node tests/engine.test.mjs
```

覆盖：规则串解析与容错、方块稳定、闪烁器周期 2、滑翔机四代平移、
边界处理、滑翔机枪 30 代周期、双缓冲交换、尺寸调整。

## 说明

生命游戏只有「活 / 死」两态，五行生克至少需要五态；相对论部分讨论的
同步更新在现实里不成立。这两块都作为**形式化类比**做，不宣称验证任何
理论。
