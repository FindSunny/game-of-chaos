# Game of Chaos

元胞自动机沙盒。两套规则共用同一个渲染与交互层：

- **生命游戏**：二态（活/死），B/S 规则可调
- **五行生克**：六态（空 + 木火土金水），按「生我 / 克我」的邻域计数演化

零构建：没有打包器、没有 npm 依赖，浏览器直接跑 ES 模块。

## 运行

```bash
# Python（Windows 上一般自带）
python -m http.server 8080

# 或者 Node
npx serve .
```

然后打开 <http://127.0.0.1:8080>。

> 直接双击 `index.html` 也能打开，但 `file://` 下浏览器会拦掉 ES 模块，
> 所以本地起个静态服务器最省事。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 画当前元素（生命游戏里就是活细胞） |
| 右键拖动 / Shift + 左键 | 擦成空 |
| 空格 | 播放 / 暂停 |
| `.` 或 `s` | 单步 |
| `c` | 清空 |
| `r` | 随机播种；生命游戏里选中图样时改为旋转 |
| `g` | 切换网格线 |
| `1`–`5` | 五行模式下切换画笔元素 |
| `0` | 五行模式下切到橡皮 |
| `Esc` | 取消待放置图样 |

顶部切模式，右侧面板调参数。设置存在 localStorage，刷新不丢。

## 两种规则

### 生命游戏

邻居数查表，`B3/S23` 表示「死细胞周围 3 个活邻居则出生、活细胞周围 2 或 3 个则存活」。
规则串可改，附 8 个预设。同步更新，边界可选环绕。

### 五行生克

状态编码：`0 空 · 1 木 · 2 火 · 3 土 · 4 金 · 5 水`

- **相生**：木生火、火生土、土生金、金生水、水生木
- **相克**：木克土、土克水、水克火、火克金、金克木

每个格子数八邻域里各状态的数量，然后按优先级判断：

1. **克制**：`克我者 ≥ 克制阈值` 且多于 `生我者` → 变空
2. **生长**：空格，邻居里某元素数量 ≥ `生长阈值` 且压得住自己的克星 → 变成「该元素所生」的状态
3. **转化**：`生我者 ≥ 生长阈值` 且多于 `克我者` → 推进到「我生」的状态

三条都不满足就保持原状。两个阈值在右侧可调，调高偏静态，调低偏沸腾。

**为什么初始状态是区块而不是随机撒点**：五态随机撒点会让每个格子的邻域里同态太少，
规则被噪声支配，画面退化成彩色噪点。成块的初始状态才有「域」可以生长、有边界可以移动。
点「随机」就是重新播一片五行区块。

## 结构

```
index.html            页面骨架
css/style.css         深色主题样式
js/core/board.js      网格数据（TypedArray 双缓冲、环绕/非环绕）
js/core/rules.js      B/S 规则解析与格式化
js/core/engine.js     生命游戏引擎（同步更新、出生/死亡统计、存活年龄）
js/core/wuxing.js     五行生克引擎（六态、生克关系、区块初始化）
js/ui/renderer.js     Canvas 渲染、坐标拾取
js/ui/patterns.js     图样库（字符画 + RLE 解码）
js/app.js             装配层：循环、输入、控件、模式切换
tests/engine.test.mjs 生命游戏回归测试
tests/wuxing.test.mjs 五行引擎回归测试
```

两个引擎接口一致（`step` / `stats` / `generation` / `age` / `setBoard`），
切换模式只换实例，循环、渲染、输入都不用改。
